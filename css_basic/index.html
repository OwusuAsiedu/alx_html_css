Welcome to My Web Page

This page demonstrates CSS Flexbox layout as part of the ALX CSS Basic project. The <article> section takes up two-thirds of the width, and the <aside> takes one-third.

Learning Objectives

In this project, I learned how to use Flexbox to position HTML elements responsively, and how to create a design that works well on both desktop and mobile.

Flexbox makes layout management easier and more predictable than using floats or older CSS positioning methods.

Sidebar / Aside Section

This is the aside section. It can contain links, ads, or additional information related to the article.

Try resizing the browser window — this layout will adapt thanks to Flexbox and the works_on_smartphone class.
